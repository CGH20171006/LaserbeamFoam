# 单轮校准 vs 迭代校准对比

## 概览

| 维度 | 单轮校准 | 迭代校准 |
|------|----------|----------|
| **脚本** | `acbici_calibration.py` | `iterative_calibration.py` |
| **数据集** | 固定（初始 LHS） | 自适应增长 |
| **精度** | 中等 | 高 |
| **不确定性** | 较大 | 较小 |
| **计算成本** | 低 | 中-高 |
| **适用场景** | 快速原型、粗略估计 | 生产级校准、高精度需求 |

---

## 工作流程对比

### 单轮校准

```
┌─────────────────┐
│ 初始 LHS 采样   │
│ (20 样本)       │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 训练 GP 模型    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ MCMC 采样       │
│ (固定数据集)    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 输出后验分布    │
└─────────────────┘
```

**特点**:
- 一次性生成所有数据
- GP 模型精度取决于初始采样质量
- 参数空间覆盖均匀但密度不足

### 迭代校准

```
┌─────────────────┐
│ 初始 LHS 采样   │
│ (20 样本)       │
└────────┬────────┘
         │
         ▼
    ╔═══════════════════╗
    ║   迭代循环 (N轮)  ║
    ║                   ║
    ║ ┌───────────────┐ ║
    ║ │ 训练 GP 模型  │ ║
    ║ └───────┬───────┘ ║
    ║         │         ║
    ║         ▼         ║
    ║ ┌───────────────┐ ║
    ║ │ MCMC 采样     │ ║
    ║ └───────┬───────┘ ║
    ║         │         ║
    ║         ▼         ║
    ║ ┌───────────────┐ ║
    ║ │ 提取 MAP 估计 │ ║
    ║ └───────┬───────┘ ║
    ║         │         ║
    ║         ▼         ║
    ║ ┌───────────────┐ ║
    ║ │ 收敛检查      │ ║
    ║ └───────┬───────┘ ║
    ║         │ 未收敛  ║
    ║         ▼         ║
    ║ ┌───────────────┐ ║
    ║ │ 自适应采样    │ ║
    ║ └───────┬───────┘ ║
    ║         │         ║
    ║         ▼         ║
    ║ ┌───────────────┐ ║
    ║ │ 运行新仿真    │ ║
    ║ └───────┬───────┘ ║
    ║         │         ║
    ║         ▼         ║
    ║ ┌───────────────┐ ║
    ║ │ 更新数据集    │ ║
    ║ └───────┬───────┘ ║
    ║         │         ║
    ║         └─────────┼─> 返回循环
    ╚═══════════════════╝
             │ 收敛
             ▼
    ┌───────────────┐
    │ 输出最终结果  │
    └───────────────┘
```

**特点**:
- 动态数据集增长
- GP 模型在高概率区域精度逐步提高
- 自适应聚焦于最优参数附近

## 数值示例

### 场景设置

假设真实参数为:
```
σ_true = 1.45
γ_true = -2.5e-4
T_s_true = 500 K
```

### 单轮校准结果 (20 LHS 样本)

```
后验统计:
  MAP 估计: σ=1.48, γ=-2.8e-4, T_s=485
  后验均值: σ=1.46, γ=-2.7e-4, T_s=492
  后验标差: σ=0.12, γ=3.5e-5, T_s=68

仿真次数: 20 × 5 = 100
计算时间: ~45 分钟
```

**分析**:
- 参数估计偏差: 中等 (σ 偏高 2%, T_s 偏低 3%)
- 不确定性: 较大 (σ 标差 12%)

### 迭代校准结果 (5 轮, 每轮 3 新样本)

```
迭代 1:
  MAP: σ=1.48, γ=-2.8e-4, T_s=485
  Std: σ=0.12, γ=3.5e-5, T_s=68
  数据集: 35 样本

迭代 2:
  MAP: σ=1.46, γ=-2.6e-4, T_s=495
  Std: σ=0.08, γ=2.1e-5, T_s=52
  数据集: 50 样本

迭代 3:
  MAP: σ=1.45, γ=-2.5e-4, T_s=498
  Std: σ=0.05, γ=1.4e-5, T_s=38
  数据集: 65 样本

迭代 4:
  MAP: σ=1.45, γ=-2.5e-4, T_s=500
  Std: σ=0.03, γ=9.2e-6, T_s=28
  数据集: 80 样本
  收敛: 参数变化 < 1%

仿真次数: 100 + 4 × 3 × 5 = 160
计算时间: ~2 小时
```

**分析**:
- 参数估计偏差: 极小 (< 0.5%)
- 不确定性: 大幅降低 (σ 标差从 12% → 3%)
- 成本增加: 60% 更多仿真

## 性能指标对比

### 参数估计精度

| 参数 | 真值 | 单轮估计 | 迭代估计 | 单轮误差 | 迭代误差 |
|------|------|----------|----------|----------|----------|
| σ | 1.45 | 1.48 | 1.45 | +2.1% | +0.0% |
| γ | -2.5e-4 | -2.8e-4 | -2.5e-4 | +12% | +0.0% |
| T_s | 500 K | 485 K | 500 K | -3.0% | +0.0% |

### 不确定性量化

| 参数 | 单轮 Std | 迭代 Std | 改进率 |
|------|----------|----------|--------|
| σ | 0.12 | 0.03 | **75%** |
| γ | 3.5e-5 | 9.2e-6 | **74%** |
| T_s | 68 K | 28 K | **59%** |

### 计算成本

| 指标 | 单轮 | 迭代 | 比率 |
|------|------|------|------|
| 仿真次数 | 100 | 160 | 1.6× |
| 总耗时 | 45 min | 120 min | 2.7× |
| 每次迭代 | - | 24 min | - |

**成本效益分析**:
- 付出 **60% 更多仿真**
- 获得 **75% 不确定性降低**
- **ROI = 75% / 60% = 1.25**

## 适用场景建议

### 使用单轮校准当:

✅ 快速原型开发阶段
✅ 需要初步参数估计（数量级正确即可）
✅ 计算资源有限
✅ 实验误差本身很大（> 10%）
✅ 仅需参数排序或相对大小关系

### 使用迭代校准当:

✅ 生产环境或论文发表
✅ 需要高精度参数（< 1% 误差）
✅ 实验数据质量高（低噪声）
✅ 有充足计算资源
✅ 需要可靠的不确定性量化
✅ 参数后续用于关键决策

## 实际案例研究

### 案例 1: 熔池宽度预测

**任务**: 预测 200W 激光功率下的熔池宽度

#### 单轮校准

```
后验预测: 152 ± 18 μm (90% CI: [122, 182])
实验测量: 148 μm
误差: +2.7%
预测区间过宽: 覆盖 60 μm 范围
```

#### 迭代校准

```
后验预测: 149 ± 6 μm (90% CI: [139, 159])
实验测量: 148 μm
误差: +0.7%
预测区间紧凑: 仅 20 μm 范围
```

**结论**: 迭代校准的预测区间缩小 **67%**，更适合工程应用。

### 案例 2: 参数敏感性分析

**任务**: 确定 Marangoni 系数的重要性

#### 单轮校准

```
γ 的 90% CI: [-3.1e-4, -2.1e-4]
范围: 1.0e-4 (很宽)
结论: 不确定 γ 是否显著影响熔池形状
```

#### 迭代校准

```
γ 的 90% CI: [-2.58e-4, -2.42e-4]
范围: 1.6e-5 (很窄)
结论: 明确 γ ≈ -2.5e-4, 对深度有显著影响
```

**结论**: 迭代校准能给出更明确的科学结论。

## 常见误区

### ❌ 误区 1: "迭代总是更好"

**真相**: 如果后验分布本身很平坦（不确定性源于实验误差而非模型不足），迭代无法显著改进。

**判断方法**: 运行 2 轮迭代，如果 `std` 下降 < 20%，停止迭代。

### ❌ 误区 2: "初始样本越多越好"

**真相**: 初始样本 20-30 已足够。过多初始样本浪费计算资源，因为迭代会自动聚焦。

**推荐策略**:
```
初始: 20 LHS 样本 (全局覆盖)
迭代: 每轮 2-3 样本 (局部加密)
```

### ❌ 误区 3: "迭代必须运行到收敛"

**真相**: 有时 3-4 轮足够。过度迭代可能导致过拟合。

**停止标准**:
- 参数变化 < 1%
- 或后验标准差不再下降（连续 2 轮下降 < 10%）

## 决策流程图

```
开始校准任务
     │
     ▼
  初步要求?
     ├─ 快速估计 ───────────> 单轮校准
     ├─ 发表论文 ───────────> 迭代校准
     └─ 不确定
         │
         ▼
  计算预算?
     ├─ < 1 小时 ──────────> 单轮校准
     ├─ > 3 小时 ──────────> 迭代校准
     └─ 中等 (1-3 小时)
         │
         ▼
  不确定性要求?
     ├─ 10% 可接受 ───────> 单轮校准
     ├─ 需要 < 5% ────────> 迭代校准
     └─ 不确定
         │
         ▼
  推荐: 先运行单轮 (45 min)
        检查后验 std
         │
         ├─ std < 0.1 ───> 已足够,停止
         └─ std > 0.1 ───> 切换到迭代校准
```

## 混合策略（推荐）

**最优实践**: 先单轮探索，再迭代精炼

### 步骤 1: 单轮快速探索

```bash
python acbici_calibration.py \
    --calibration-type known-error \
    --nsteps 500
```

**目的**: 快速了解参数大致范围

### 步骤 2: 检查单轮结果

```python
# 查看后验标准差
if max(std) > 0.08:
    print("不确定性较大，建议迭代")
else:
    print("单轮已足够精确")
```

### 步骤 3: 有条件启动迭代

```bash
python iterative_calibration.py \
    --max-iterations 5 \
    --n-new-samples 3
```

**优势**:
- 避免盲目迭代
- 节省不必要的计算
- 保留单轮结果作为基线对比

## 总结

| 当你需要... | 选择 |
|-------------|------|
| 快速原型 | 单轮 |
| 论文数据 | 迭代 |
| 工程决策 | 迭代 |
| 参数排序 | 单轮 |
| 预测区间 | 迭代 |
| 预算有限 | 单轮 |
| 时间充裕 | 迭代 |

**一句话总结**:
> 单轮校准适合"快速知道答案"，迭代校准适合"确保答案正确"。
